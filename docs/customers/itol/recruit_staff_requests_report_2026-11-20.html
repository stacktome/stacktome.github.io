Methodology

Each row counts the review invitation requests that staff submitted through ITOL’s request form for that desk. Every request is counted, including those the system held or suppressed (for example because the student had recently been invited), so these figures show what staff asked for, not the number of invitations delivered. A request repeated by the same staff desk for the same student within the same minute is counted once. Requests that come through HubSpot are not submitted by a desk and are not included. November covers November 1–20; the most recent request recorded was on November 19. All 25 desks are listed, including those with no requests in the period.
