Campaign period — determined from data, not assumed: the account's first-ever invite send is 2026-02-02 (campaign 532, FR — confirmed via an unfiltered MIN(_date) across full invite history, not the report's default lookback). This report therefore covers the account's entire campaign lifetime to date: 2026-02-02 through 2026-08-10 (the day before generation; 2026-08-11 itself is excluded as still in progress). FR is the only market with meaningful history — DE, IT and ES all launched together on 2026-07-16, so their figures reflect roughly 3.5 weeks of activity, not 6+ months.

Attribution method: reviews are attributed to a campaign when review.order_id = invite.contact.order_id (case-insensitive), using the campaign's full invite history as the attribution map. Supersmart uses product review invites — rating uses product_rating, falling back to order_rating when a product-level rating isn't set. Each review is counted once per (order, product, rating) combination.

Correction vs. this account's prior published reports: earlier reports (incl. 2026-07-24) deduplicated attributed reviews on (order_id, rating) only, without product_sku. That collapses genuinely distinct reviews whenever the same order contains two different products both rated the same score — verified against this period's data, it undercounted FR by 5 reviews (292→297 correct) with no effect on DE/IT/ES. This report uses the corrected, product-scoped dedup throughout; the account-wide total moves from what would have been 339 to the validated 344. No prior report needs restating — the earlier weekly windows were each too short to hit this collision case more than once or twice, but it's worth knowing the dedup key going forward.

Market expansion since the last report (2026-07-24): no new markets since then — still FR (532, live since Feb 2) plus DE (736), IT (738), ES (740), all live since Jul 16. Each market has a paired response campaign (533/737/739/741, targets trustpilot) that sends a follow-up email when a Trustpilot review comes in on an invited order — not a product invite, and excluded from all invite/review-rate figures above and below. (The 2026-07-24 report described these as "Google-review-response" campaigns; the campaign API confirms their target is trustpilot, not Google — corrected here.)

3,941 additional reviews across the period (avg 4.59★) had no matching invite of any kind and are organic; not included in the campaign figures above.
